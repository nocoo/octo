The complete approved foreground is translated 96 native pixels right, without
scaling or recoloring, to keep its side fin clear of the rounded outline. The
lower neck is an intentional frame entry. Original generation and both finishing
passes remain in Hexly. All fully opaque foreground RGB values are unchanged.

The same 24 px transparent mark is used in expanded, collapsed and mobile rails;
its existing button retains the sidebar toggle handler and accessible name.
Small marks have no tile, CSS corner mask, shadow or color filter. At favicon
size the long snout and crown remain useful; individual facets soften.

Consumer audit: the application has one shared shell and no independent login
page. Cloudflare Access remains external. Page and data loading use Basalt
skeleton bars, not a library logo, and remain unchanged. User avatars, business
icons, auth, routes and product theme are outside this adoption.

This is local source adoption only. It does not establish a push, release,
deployment, R2 publication or successful production monitoring observation.
